# bolttable

[![Go Reference](https://pkg.go.dev/badge/github.com/cplieger/bolttable.svg)](https://pkg.go.dev/github.com/cplieger/bolttable) [![Go version](https://img.shields.io/github/go-mod/go-version/cplieger/bolttable)](https://github.com/cplieger/bolttable/blob/main/go.mod)

bolttable will give your Go code typed tables, declared indexes and a change feed over one bbolt file. This first release holds the module and no API yet.

It depends only on bbolt and the standard library, needs Go 1.27.2 or later and is licensed under Apache-2.0.

## Disclaimer

This project is built with care and follows security best practices, but it is intended for personal / self-hosted use. No guarantees of fitness for production environments. Use at your own risk.

This project was built with AI-assisted tooling using [Claude](https://claude.com), [GPT](https://openai.com), and [Kiro](https://kiro.dev). The human maintainer defines architecture, supervises implementation, and makes all final decisions.
